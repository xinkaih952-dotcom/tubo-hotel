# 涂泊酒店（南宁东站店）营收台账 & 收支利润系统

两个网页，全部在浏览器里运行，不需要服务器：

| 页面 | 给谁用 | 做什么 |
| --- | --- | --- |
| `index.html` 营收台账 | 前台 | 每天录入营收（按营收表的列）、明细表核对、早晚班交班收款、现金押金与备用金、导出当月 Excel |
| `finance.html` 收支利润 | 店长 / 会计 | 月底渠道结算对账、每月录入成本、净利润与毛利率、成本结构、利润趋势、月度利润表 |

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` / `script.js` | 前台营收台账的页面和功能 |
| `finance.html` / `finance.js` | 收支利润的页面和功能 |
| `common.js` | 两个页面共用：酒店配置、收入渠道、收款方式、成本项目、计算方法 |
| `style.css` | 两个页面共用的样式 |
| `data.js` | 2025.01–2026.08 月度营收历史（来自利润表） |
| `finance-data.js` | 2025.01–2026.08 月度成本历史（来自利润表，**含工资**） |
| `daily-data.js` | 2025.01–2026.08 每日营收、现金押金、每月实际结算总额及差异说明、备用金备注（来自营收表） |

所有文件放在**同一个文件夹**里，文件名不要改。

## 日常流程

1. **前台每天**：打开 `index.html` →「每日营收」录入出租间数、系统平均房价、各渠道收入（顺序和营收表一样），再填「系统明细表金额」，网页自动核对小计是否一致。
2. **每次交班**：「交班收款」选早班 / 晚班，填微信、支付宝、现金、挂账。系统自动和当天「前台应收」对账。
3. **现金**：「现金押金」填房费押金、早餐 / 小商品 / 税点现金、现金退款，自动算出现金合计和应投款；每周盘点备用金也记在这里。
4. **月底**：前台点「导出当月 Excel」（含每日营收、交班明细、现金押金、备用金四张表）发给店长。
5. **店长**：打开 `finance.html` →「导入前台 Excel」→「渠道结算对账」填各渠道实际到账 →「月度成本录入」填成本 → 查看利润、导出利润表。

如果店长和前台用的是**同一台电脑、同一个浏览器**，收支利润页会直接读取前台数据，不用导入。

## 常改的设置（都在 `common.js` 开头）

- `TOTAL_ROOMS`：总客房数（目前 68 间）
- `ROOM_CHANNELS` / `NON_ROOM_ITEMS`：收入渠道。`active: false` 表示不在录入表里显示（如华佗代理）；`atDesk: true` 表示前台收的钱，参与交班对账
- `PAYMENT_METHODS`：交班收款方式（要加「银行卡」，加一行即可）
- `COST_GROUPS`：成本项目，结构和酒店利润表一致

## 计算口径

- 入住率 = 出租客房数 ÷ 68 间；平均房价按酒店系统数；RevPAR = 平均房价 × 入住率
- 月度、全年的入住率和平均房价按间夜加权，不是各月简单平均
- 毛利 = 总营收 − 主营业务成本 − 非主营业务成本；毛利率 = 毛利 ÷ 总营收
- 净利润与酒店利润表算法一致：用本系统数据重算 2025.01–2026.08 的净利润，和利润表逐月相同
- 营收表小计 = 美团 + 携程 + 门店POS机 + 门店现金 + 飞猪 + 抖音 + 华佗 + 小商品POS机 + 早餐收入 + 发票税点，应等于系统明细表
- 现金合计 = 门店现金 + 房费押金 + 早餐现金 + 小商品现金 + 税点现金；现金投款 = 现金合计 − 现金退款
- 结算差异 = 实际结算 − 系统录入；新月份填了实际结算后，利润表里该渠道收入改用结算数

## 数据保存在哪里

- 每天录入的营收、交班记录、每月成本，都保存在**打开页面的那台电脑的浏览器**里（localStorage），不在这些文件里，也不会上传。
- 换电脑、换浏览器、清理浏览器缓存都会看不到之前的数据，请定期导出 Excel 备份。
- 更新这些文件不会丢数据，只要文件夹位置不变。

## 上传到 GitHub 之前

`data.js`、`daily-data.js` 是酒店营收，`finance-data.js` 是成本和工资。仓库如果设为**公开（Public）**，任何人都能看到。

- 建议把仓库设为 **Private**；或者上传时不传这三个文件（页面照常能用，只是没有历史数据）。
- 每天录入的数据不在文件里，不会被上传。
